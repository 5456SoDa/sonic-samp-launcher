# รายงานตรวจสตริงไทยในไบนารี SampLauncher.exe (v2.2)

**วิธีตรวจ:** dump จาก **#US heap ของ .NET metadata** ซึ่งเป็นที่เก็บ string literal ของโปรแกรมจริง ๆ
(เครื่องมือ `_launcher_dev/tools/UsDumper.cs` → ผลลัพธ์ `_launcher_dev/tools/us_dump.txt` 317 สตริง)

**สรุป: ข้อความเพี้ยนเป็นของจริงในไบนารี ไม่ใช่อาการตอนถอดของผม** — ต้องแก้ literal ในซอร์สโค้ด C# แล้ว build ใหม่
เจอ 2 กลุ่ม: (A) คำไทยผิด/สั่งคลั่งแบบพิมพ์ผิดหนัก และ (B) mojibake แบบ double-encoding

## B. Mojibake (double-encoding) — ข้อความในวงเล็บถูกเซฟผ่าน encoding ผิดมา

| #dump | ข้อความปัจจุบัน | ควรเป็น |
|---|---|---|
| 0131 | `✖ ไม่สามารถต่ออินเทอร์เน็ต (เธฅเธดเธชเธ•เน...ได้)` | `✖ ไม่สามารถต่ออินเทอร์เน็ต (ลิสต์สาธารณะใช้ไม่ได้)` |
| 0132 | `✓ ลิงก์ samp://ip:port พร้อมใช้ (เธเธฅเธดเธ...ได้)` | `✓ ลิงก์ samp://ip:port พร้อมใช้ (คลิกจากเว็บ/ดิสคอร์ดได้)` |

สาเหตุที่พบบ่อย: คัดลอกข้อความไทยผ่านโปรแกรมที่อ่าน UTF-8 เป็น CP874/Latin-1 แล้วเซฟกลับ
แล้วเอาผลที่เพี้ยนไป paste ในซอร์สต่อ → ให้พิมพ์ใหม่ตรง ๆ ตามคอลัมน์ "ควรเป็น"

## C. ให้เนื้อสม่ำเสมอ (ไม่ผิด แต่ควร unify)

- คำว่า **มอด / ม็อด** ปนกันทั้งไฟล์ (0109, 0110, 0123, 0125, 0126 ใช้ "มอด") → มาตรฐานราชบัณฑิตฯ คือ "ม็อด" แนะนำใช้ทั้งโปรเจกเดียวกัน
- คำว่า **ต่ออินเทอร์เน็ต** (0131, 0267) กับ **เชื่อมต่ออินเทอร์เน็ต** (0087, 0130) → เลือกใช้คำเดียว

## D. สรุปที่เจอว่า "ปกติดี" เพื่อความอุ่นใจ

ข้อความส่วนใหญ่ (ราว 280+ สตริง) สะกดถูกและอ่านลื่น เช่น หน้าเซิร์ฟเวอร์, แกลเลอรี, RCON, health check,
ข้อความ WinAPI error (0281–0290), config keys — ปัญหากระจุกอยู่แค่กลุ่ม validate/error บางก้อนตามตาราง A
